# Employee Management System

A modern, full-stack employee management system for managing staff data, leave requests, approvals, and attendance — built with Next.js, TypeScript, and Prisma.

## 🚀 Features

- 🧾 **Employee Data Management**  
  Add, edit, delete, and view employee profiles.

- 🗓️ **Leave Request & Approval Workflow**  
  Submit leave requests, track approval status, and manage leave balances.

- ✅ **Approval System**  
  Managers and HR can approve or reject requests with e-signature.

- 📊 **Dashboard & Statistics**  
  Real-time monitoring of forms, attendance, and employee status.

- 🧠 **Intern Attendance Monitoring**  
  Includes attendance tracking for internship students.

- 📬 **Email Notifications**  
  Automatic emails for submission and approval updates.

## 🛠️ Tech Stack

- **Frontend:** Next.js 15 (App Router), TypeScript, TailwindCSS  
- **Backend:** Next.js API Routes  
- **Database:** PostgreSQL / MySQL (via Prisma ORM)  
- **Authentication:** Custom Auth / Token-based  
- **Notifications:** Email / WhatsApp Integration (Planned)  
- **Deployment:** Vercel (Frontend), Railway (Database)
